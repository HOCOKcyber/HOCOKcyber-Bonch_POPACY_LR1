# EquipmentManagement

Приложение для управления материально-техническим обеспечением учебного
процесса.

## Запуск проекта

Откройте два отдельных терминала в корневой папке решения.

### 1. Запуск API

В первом терминале выполните команду:

``` bash
dotnet run --project EquipmentManagement.API
```

### 2. Запуск Blazor Front

Во втором терминале выполните команду:

``` bash
dotnet run --project EquipmentManagement.Front
```

После запуска откройте в браузере адрес, который будет указан в выводе
`EquipmentManagement.Front`.
